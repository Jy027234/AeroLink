管理员在“系统设置 → AI 智能体 → 模型管理”编辑“DeepSeek 业务助手”，填写 API Key 并保存，然后点击“测试连接”。成功后在智能体编辑页试运行，再使用真实邮件、RFQ 和客户报价样本评估四个业务入口的输出。
