# D11 商业修订与历史文件验收

日期：2026-09-08。承接 D10 多行商业链路；币种、交易范围和审批额度沿用已确认政策。

## 商业修订

- `commercialRevision` 与乐观锁 `version` 分开。`POST /quotations/:id/revise` 必须提交原并发版本、修订原因和完整的新报价（包括明确的有效天数）。
- 新报价使用独立 ID、根报价号加 `-R2/-R3`、上一版/根版关联，从 `DRAFT` 开始，没有继承审批、签名或成交计数。原版价格、有效期、审批和成交订单保持原记录。
- 旧版保留可读，`supersededAt` 阻止再次提交、审批、发送或成交；历史查询按访问范围返回版次，不包含成本字段。并发修订通过 RFQ/报价 CAS 和上一版唯一关系限制为一个后继。
- 不允许修订更换客户、需求或交易模式。已全部成交报价交给订单变更处理；部分成交的逐行报价只能覆盖需求尚未成交的数量。旧单行报价在生成订单后不再修订。
- 旧报价已有库存预留时，在修订事务中释放并清零；任何后续创建失败一起回滚。邮件仍在投递时阻止修订，避免不确定投递结果与商业变更交错。旧失败邮件重放也不能发送已被修订的报价。
- 已有审批依据的报价不能通过审批接口原位替换成本来源，需要商业修订。历史缺失来源仍可在未具备原审批证据的情况下显式补录并重新审核。

## 有效期及历史文件

- `expiryDate` 是唯一交易判定依据；`validityDeadline` 仅作兼容校验/双写。两个字段指向不同时间瞬间、字段非法或 canonical 截止已到达，均不能审批/发送/接受；不借用较晚字段延长报价。
- 审批事务冻结公开渲染快照、当时客户名称、条款、全部报价行、HTML、捕获时间和哈希，使用 `GeneratedDocument` 的 `QUOTATION_PDF` 类型。对客快照不含成本或毛利。
- 首次下载/发送保存最终 PDF 字节及 SHA-256；后续下载和邮件重试读取原字节。并发首次渲染通过 CAS 只保存一份，数据库触发器阻止替换已冻结的内容和 PDF。
- 已有历史报价但没有冻结记录时，不用当前客户/模板数据冒充原文件；需要核对原始文件或审批新的修订版。未审批草稿可下载有明确水印的预览。
- 已存在但缺少可信快照的旧 `QUOTATION_PDF` 不被原位补写；审批事务明确失败并回滚，避免审批成功后才发现文件不可发送。
- 正式报价 PDF 为公开版本，内部成本留在有权限的业务视图。PDF bytes 不进入文档列表、详情或报价/订单嵌套 JSON。既有订单合同继续使用原 `contentHtml` 和原生成时间。
- 本批增加 `20260908000600_quotation_commercial_revisions` 与 `20260908000700_immutable_quotation_documents`。旧记录不批量伪造 revision 历史、有效期、审批或冻结文件；历史日期冲突仍需依据原始单据核实。

## 已取得的真实证据

`server/src/scripts/checkQuotationRevisionIntegration.ts` 仅在显式 `AEROLINK_REVISION_INTEGRATION=true` 和本机 `aerolink_revision_test_*` 库运行，使用 Serializable 事务和合成数据。

- 旧单行报价 `100 × 3` 审批后修订为 `120 × 3`，原价格/有效期/审批不变，新版为无审批的草稿，旧版发送/成交被拒绝。
- 两条需求 `4/3` 件先成交第一行 2 件，再以 `2/3` 件、单价 125 修订，合计 625；超出剩余需求的修订回滚，原订单、订单行与合同保持一致。
- 两个并发修订仅一个成功，数据库只保留一个后继版。
- 修订中新来源无效时，原库存仍为预留状态、预留数量不变且没有新版本；有效修订成功后才释放。发送与修订并发仅一方成功，待投递邮件阻止修订。
- 旧文件缺少冻结快照时审批失败，真实 PostgreSQL 中没有留下通过的审批记录；新修订也不会沿用旧签名。
- 生成实际 Chromium PDF 后修订报价并修改客户名称，再次读取旧 PDF，字节与 SHA-256 完全一致，HTML 仍保留原客户名称；直接替换冻结 HTML 被真实 PostgreSQL 触发器拒绝。
- HTTP E2E `quotation-revisions.spec.ts` 已通过，覆盖部分成交后修订、强制重审、幂等重放、旧版写入阻断、版次导航数据、跨用户访问拒绝和销售成本脱敏；与 D10 多行 HTTP 流程组合 2 项通过。
- 浏览器 `quotation-revisions-ui.spec.ts` 实际完成部分成交后修订：原单价正确回显，填写原因、14 天有效期、成本依据和新价格后得到 USD 990 的 v2 草稿；原 USD 1,000 报价和已成交订单保留。销售从文档列表/详情/下载入口也能取得同一公开历史文件。

过程日志保留于 Windows Temp：`aerolink-revision-postgres-verified-20260908.log`、`aerolink-revision-http-20260908.log`。最终全量及浏览器表单结果补入优化执行记录。
